# 🔥 Firefox Compact Theme

A minimal, custom `userChrome.css` that shrinks the Firefox tab bar and address bar for a clean and compact browsing experience.

Created by **Anuprash Subedi ([@learnerAnuprash](https://github.com/learnerAnuprash))**

---

## ✨ Features

- 🧼 Compact tab bar and address bar
- 🖤 Flat look: no shadows, borders, or extra padding
- 🪶 Lightweight — only uses CSS, no add-ons
- 💻 Works across **Windows**, **macOS**, and **Linux**
